# ADR 0001 — Adapt Spec Kit without inheriting its ceremony

Date: 2026-09-28. Status: amended after the owner's subtraction correction.

The first adaptation generated fifteen three-file bundles and a universal close
stage. That made the inherited subsystem structure more precise before establishing
whether its mechanisms were needed. More detail alone was not a sufficient correction.

Keep numbered specs, FR/SC traceability, `.specify` policy/templates and familiar OMP
commands. One spec can own behavior, design, work and evidence; supplemental files
must have a reader. Commands are tools, not a required sequence. Measurement is for
numerical claims, not closure of every feature. Five user workflows replace the
subsystem portfolio. Release selected working scope using one short checklist.

A verbatim workflow copy retains unwanted obligations. Discarding all shared structure
loses useful traceability. This amendment keeps traceability while removing required
artifacts/stages. The risk is under-specification; retain concrete ownership, failure
and acceptance where the selected behavior actually needs them.

The audit remains in-session as requested. No independent approval, installed dispatch
framework, host command discovery or new runtime capability is implied.
