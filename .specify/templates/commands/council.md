spec, change or question. This command is a tool, not a mandatory workflow stage.

Use only for the requested consequential question. Independent review must be available and authorized; never install orchestration or spawn agents against user preference. An in-session audit is labeled self-review. Verify findings against source and record disposition where the decision lives. This is not a routine release stage.
