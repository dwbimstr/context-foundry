# /plan

Read `.specify/memory/constitution.md` for project policy. Target: the user-supplied
spec, change or question. This command is a tool, not a mandatory workflow stage.

Use the selected spec and current code. Compare meaningful interface alternatives for consequential boundaries. Identify ownership, durable state, failures, recovery, limits and removal of old paths. Put the design in the spec unless a separate plan helps a real reader. Do not prebuild a framework for deferred consumers.

Apply KISS without reducing the selected capability: preserve its quality and failure
guarantees, minimize independent owners and coordination, and explain any temporary
limitation. Necessary sophistication belongs behind a small explicit interface.
