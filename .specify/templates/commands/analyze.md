# /analyze

Read `.specify/memory/constitution.md` for project policy. Target: the user-supplied
spec, change or question. This command is a tool, not a mandatory workflow stage.

Read the selected spec and any actual supplemental documents. Check behavior/design/work/acceptance, source assumptions and real dependencies. Identify concrete failure scenarios. Check whether added mechanisms are necessary. Do not require missing optional files or restart a portfolio-wide review for a small change.

For changed boundaries, follow the caller through ownership, publication and failure.
Check repeated operations and interactions with the nearest feature, not only each
feature alone. Keep fixes and acceptance with their existing owner; call out proof
limits rather than adding a general coordination framework.
